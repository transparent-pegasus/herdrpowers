# Upstream Refresh — v7.0.2: Fewer Brainstorming Questions, Helpers Bound to the Working Tree

Adopts the payload-relevant changes from upstream v7.0.2. Brainstorming
asks a question only when the answer would change what gets built and
nothing already answers it. It asks why first when the user has not said,
names the options with a recommendation when a choice can be named,
states process calls instead of asking about them, and ends its first
message with a short design to approve when nothing is open.

The pane-driven-development and executing-plans helpers now act on the
working tree of the current directory, through a new `pdd-repo`, and take
`-C DIR`. Outside a repository, or before its first commit, they stop
with exit `2` and say what to do. `task-brief` accepts IDs such as `A1`,
`6b`, and `2.1` without prefix matches, refuses a brief that an unclosed
code fence ran on, and lists task-shaped headings when none use the word
`Task`. Every skill that names a helper now says to run it by its
absolute path from the working tree. The systematic-debugging pressure
scenarios and creation log leave the installed skill for `tests/`.

Bumps the pack to **1.24.0** across its four versioned manifests and
`package.json`: brainstorming behavior and helper exit behavior change.
The Codex marketplace file has no version field.

## Reconciliation decisions

- **The pack's wording stays.** New brainstorming text says "the user",
  not "your human partner", and the pack's codegraph sentence stays after
  the new "or reopen what they've already decided".
- **A first-message approval goes to step 4, not straight to a plan.**
  Upstream's new text ends "go on to the plan". Here it reads "go on to
  step 4", whose `/quick` exception continues with workspace isolation.
- **Design documents stay uncommitted** at `<DESIGN_DOC_PATH_PATTERN>`.
  Only "Otherwise, ask" becomes "Otherwise, pick a sensible place and say
  where", matching upstream's process-calls rule.
- **The `adhoc` workspace survives `-C`.** With no plan argument, or `-`,
  `pdd-workspace` still resolves the marker-less shared `adhoc` directory,
  now also through `-C DIR`. Upstream's assertion that a missing plan
  argument exits `2` stays deliberately replaced, as in earlier refreshes.
- **Helper names follow the pack.** The new resolver is `pdd-repo`, beside
  `pdd-workspace`. Upstream issue numbers are left out of ported comments,
  as before.
- **Mentions that run nothing name the helper without a path.** A table
  cell and a red-flag bullet in the PDD entry point now say "the
  `task-brief` helper", instead of carrying run instructions where nothing
  is run. Every actual run instruction carries the absolute-path wording.
- **The skill-layout guard admits two payload names.**
  `pane-driven-development/test-author-brief.md` and
  `references/test-authoring.md` are delegation payload, not scenarios.
  They are excluded by exact path; any other `test-*.md` or
  `CREATION-LOG.md` under `skills/` fails.
- **Licensing stays MIT.** `NOTICE` now also covers `tests/skill-layout/`,
  `tests/pdd-helper-paths/`, and `tests/systematic-debugging/`.

+if [ "${1:-}" = "--with-commit" ]; then

+  shift
+fi

+  exit 2
+fi
