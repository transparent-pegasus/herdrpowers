# Upstream v6.0.2 Refresh

Adopts the Superpowers 6 task-review and visual-companion hardening refresh from `obra/superpowers` through v6.0.2 (`b62616f`). This update keeps `superpowers-extended` as a template payload with mirrored `.agents/` and `.claude/` trees, named `code-reviewer` / `test-engineer` agents, repo-agnostic placeholders, and uncommitted design/plan artifacts.

## Upstream coverage

Adopted:

- **Subagent-driven development v6 review model.** The old per-task `spec-reviewer-prompt.md` and `code-quality-reviewer-prompt.md` were replaced with a single `task-reviewer-prompt.md` that returns separate spec-compliance and task-quality verdicts. Added upstream's file handoff scripts, `scripts/task-brief` and `scripts/review-package`, plus pre-flight plan review, model-selection guidance, final broad review guidance, and the durable progress ledger.
- **Writing-plans structure.** Plans now include Task Right-Sizing, a `Global Constraints` block, and per-task `Interfaces` blocks so implementers and reviewers receive explicit contracts.
- **Visual companion hardening.** Adopted the authenticated per-session key flow, safer file serving, reconnect/paused status UI, same-port project sessions, 4-hour idle default, `--open`, Windows lifecycle hardening, and safer stop ownership checks.
- **Worktree and finishing updates.** Adopted project-local worktree preference, removal of the legacy global fallback, native-worktree deference, and provenance-based cleanup updates.
- **Skill wording refinements.** Adopted vendor-neutral language where it fits this pack, read-only review guidance, code-review reception refinements, TDD anti-pattern link fix, systematic-debugging trigger fix, and writing-skills form-selection / micro-test guidance.

Skipped:

- Upstream plugin/harness packaging for Claude, Codex, Cursor, OpenCode, Kimi, Pi, Antigravity, hooks, release metadata, package scripts, and tests. This fork is a portable template overlay, not those upstream plugin distributions.
- Upstream `evals/` history and submodule moves. This pack does not ship upstream's eval harness.
- Upstream committed design specs and implementation plans. This fork keeps design documents and plans as target-repository coordination artifacts that are not committed.
- Upstream `using-superpowers` bootstrap and per-harness reference tree. This fork already uses `AGENTS.md` / `CLAUDE.md` entrypoints and explicit mirrored skill trees.
- Upstream removal of named review agents. This fork continues to require named `code-reviewer` and `test-engineer` agents.

## Reconciliation decisions

- **Named reviewer preserved.** Upstream's new task reviewer is translated to `Agent tool (subagent_type: code-reviewer)` instead of `general-purpose`. The final whole-branch review continues to use `requesting-code-review`.
- **Test-engineer boundary preserved.** Upstream wording that says implementers write tests was rewritten: implementers request tests through `requesting-test-creation`, receive results through `receiving-test-creation`, and run existing verification commands. Task reviewers check test evidence and route test-code or coverage concerns back to `test-engineer`; they do not review test code directly.
- **Template placeholders preserved.** Concrete upstream `docs/superpowers/...` paths remain `<DESIGN_DOC_PATH_PATTERN>` and `<PLAN_PATH_PATTERN>`, and validation/test placeholders remain target-repository initialization inputs.
- **Dual tree mirror maintained.** Every adopted skill change was applied to both `.claude/skills/` and `.agents/skills/`, with `.agents` retaining `superpowers:` skill prefixes where required.
- **Codegraph guidance preserved.** Optional codegraph discovery remains in brainstorming, plan writing, task implementation, scoped task review, code review, and review-feedback handling.
- **Installed changelog model preserved.** Root `changelogs/` tracks this source repo's upstream merge history. Installed repositories still use `.superpowers-extended/changelogs/` as their ignored update cache and sync-point store.
