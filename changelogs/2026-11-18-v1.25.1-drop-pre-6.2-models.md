# Drop pre-6.2 model strings (v1.25.1)

The shipped `roles.yaml` no longer carries `codex@GPT-6-Astra` or
`codex@GPT-6.1-Sol` fallbacks; only the GPT-6.2 keys remain. A consumer
config that still pins GPT-6-Astra or GPT-6.1-Sol now resolves no codex
substitute from the shipped defaults; re-pin it to GPT-6.2 or add its own
fallback key.

Footer-reader fixtures, mismatch tests, and the composer-keys footer table use
current model strings: `GPT-6.2-Sol` replaces `GPT-5.6-Luna`, the mismatch
model is `GPT-6.2-Astra`, and the OpenCode footer reads `GPT-6.2 Sol`. The
layouts of the captured screens (`codex.txt`, `codex-wrapped-composer.txt`,
`codex-transcript-mentions-grok.txt`, `opencode.txt`) are unchanged; only
their model strings were rewritten. `cursor-model-picker.txt` keeps its
captured picker list unchanged.
