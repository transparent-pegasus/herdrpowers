# v1.13.0 — Drop `rtk` from payload commands, gate documentation impact in `/execute_parallel`

## Summary

Three pack-native fixes, no upstream sync and no `roles.yaml` change.

**`rtk` leaked into the shipped payload.** Every command example in `skills/using-herdr-sibling-panes/SKILL.md`, the four `pane-driven-development` briefs, and `skills/requesting-code-review/review-brief.md` was written as `rtk herdr ...`, `rtk "$COMPOSER_SUBMIT" ...`, `rtk sleep 0.40`, even `rtk make lint` inside a sample instruction string. `rtk` is one maintainer's local token-saving proxy, installed and hook-driven on that machine; it is not a dependency of this pack and does not exist in an installed user's `PATH`. Every one of those lines is now the bare command. The `HERDR_COMPOSER_MIN_COLS=24` retry row in the failure-handling table loses its prefix for the same reason.

**`probe-composer.sh` tripped the failure mode its own skill documents.** SKILL.md tells orchestrators to keep the word `run` out of instruction prose, because herdr's cursor rules match any recent-scrollback line beginning with `run ` and pin the pane at `blocked` — a state the helper refuses, and only `/clear` clears. The probe's own instruction said "Make no edits and run no commands", so a wrap at the right column pinned the very pane it was probing. It now says "execute no shell commands", with a comment naming the rule and pointing at the SKILL.md section so the phrasing does not regress.

**`/execute_parallel` had no documentation-impact gate.** The update list was a bullet buried in Step 1's track-extraction instructions, with no gate, no route, and Steps 4 and 5 referring back to it by the wrong step number. It is now Step 3 — its own gated step keyed on `assignments.documentation-impact-review`, routed by its resolved role and mode, with the remaining steps renumbered (implementation 4, documentation update 5, verification 6, final review 7, integration 8) and every cross-reference in this file and in `commands/full_cycle.md` updated. `docs/roles.md` adds `/execute_parallel` to that gate's row, which previously listed only `/execute`, `/full_cycle`, and `/quick`. The list stays post-integration by construction: documentation is never a parallel track.

**One invariant restated in `commands/init.md`.** The warning against writing a config that routes a review to the implementing role was wrong and contradicted the independence rule: independence is the reset session, not role or pane identity. Only the two-Reviewer-slots-same-agent-type warning survives.
