# v1.28.0 — Antigravity plugin

## Summary

Antigravity becomes a supported harness:

```bash
agy plugin install https://github.com/transparent-pegasus/herdrpowers
```

`.antigravity-plugin/plugin.json` is the native manifest, the location
Antigravity documents for repositories that also ship other harnesses'
manifests. Antigravity loads `skills/` from the plugin root by default. Its
plugins cannot ship commands, so the manifest's `skills` path adds
`.antigravity-plugin/commands/<name>/SKILL.md`: one wrapper per workflow,
carrying the workflow's name and description, that tells the agent to read
`commands/<name>.md` and follow it.

## Details

- **Wrappers, not the command files.** Antigravity's loader has no commands
  component (`agy plugin validate`: `commands: never loaded: plugins have no
  commands`), and a skill must be a `SKILL.md` in its own folder: pointing
  `skills` at `./commands/` or at a command file adds nothing. Symlinked or
  copied command files would load, but Antigravity reads only the first
  24,000 bytes of a `SKILL.md` body, and `commands/init.md`'s body is 28,127
  bytes. The cut would drop its last verification checks, its report step,
  and all of `Execution Requirements`. A wrapper keeps `commands/` the single
  source, and the agent reads the whole file.
- **Not the Claude Code conversion.** `agy plugin install` already accepts
  this repository as a Claude Code plugin and converts it, but names the
  workflows `herdrpowers-cmd-<name>` and truncates `init` the same way, and
  `agy plugin validate` reports that the unconverted directory does not load.
- **Interactive names.** The Antigravity CLI names a plugin skill's slash
  command after its path relative to `skills/`, so the wrappers appear as
  `/herdrpowers:..:.antigravity-plugin:commands:<name>`. Listing each folder
  or `SKILL.md`, a root-level folder, a plugin `skills.json`, and a
  plugin-prefixed frontmatter `name` all produce the same `..:` form. Typing
  `/herdrpowers:<name>` selects the wrapper for six workflows; for `plan` the
  first completion is `/herdrpowers:writing-plans`, which Enter selects (and
  submits, when arguments follow the name), so
  the README and `docs/workflows.md` say to pick `plan` from the menu. The
  built-in `/plan` stays a separate entry. Moving the wrappers into `skills/`
  would give them plain names but load them as skills on every other harness,
  next to the commands.
- **Install, don't import.** `agy plugin import claude` treats a Claude Code
  copy as a Claude Code plugin even with the native manifest present. It
  converts the commands to `herdrpowers-cmd-*` skills, deletes `commands/`,
  and keeps `.antigravity-plugin/`, so 30 skills load, including seven
  wrappers whose workflow files are gone. The README says to install instead;
  `agy plugin install` over an imported copy replaces it with the 23-skill
  plugin. A wrapper whose workflow file is missing tells the agent to stop and
  ask for that reinstall.
- **Expected validation warnings.** `agy plugin validate .` passes with two
  warnings that a multi-tool repository carries by design: the root
  `AGENTS.md` (Antigravity loads plugin rules only from `rules/`, so the
  maintainer instructions never reach users) and `commands/`. The missing
  logo is a note; it matters only for the curated Antigravity Marketplace.
- `tests/antigravity/plugin.test.mjs` checks that the manifest carries the
  `package.json` name and version, and that its `skills` path holds exactly
  one wrapper per `commands/*.md`, each with that workflow's name and
  description and a path that resolves to that workflow's file.
- `README.md` gains the install section and the menu note; `CLAUDE.md`,
  `AGENTS.md`, `docs/skills.md`, and `docs/workflows.md` name the new manifest
  and wrappers; `CLAUDE.md` adds the wrappers to the workflow-editing rule and
  the new test and `agy plugin validate .` to its validation list. The pack
  version moves to 1.28.0 in `package.json` and all five manifests.

## Verification

Against Antigravity CLI 1.5.12, using throwaway copies of the plugin:

- `agy plugin validate`: 23 skills (16 plus 7 wrappers), the two expected
  warnings, and the logo note. `agy plugin install` of a copy and
  `agy plugin list --json` under an isolated `HOME` list the same 23.
- With the copy in a scratch workspace's `.agents/plugins/`,
  `agy -p "/herdrpowers:init …"` read the wrapper and then all 372 lines of
  `commands/init.md`, through its final `## Execution Requirements` heading.
- The agent read a file in a plugin's root, outside any skill folder, under
  `~/.gemini/config/plugins/`, the global install location. The temporary
  plugin used for that check was removed afterwards.
- In the interactive CLI: the menu names, the six correct completions, the
  `plan` completion, and the separate built-in `/plan` described above.
- In a clean session, `agy -p "Let's make a react todo list"` read
  `skills/brainstorming/SKILL.md` first and answered with a question,
  writing no files.
- Under an isolated `HOME` holding a Claude Code install record,
  `agy plugin import claude` produced the 30-skill copy described above, and
  `agy plugin install` over it restored the 23-skill plugin.
- Only the CLI was exercised. The Antigravity App and IDE share the plugin
  format and the `~/.gemini/config/plugins/` location but were not run.
- The new test failed in all 16 cases before the change, because the files
  were missing, and passes after it. Six deliberate breaks each fail their
  test: a removed wrapper, a drifted description, a wrong path depth, a
  version bumped in one place only, a workflow without a wrapper, and a wrong
  `skills` path.
- `claude plugin validate` for the plugin and the marketplace, and the rest
  of `CLAUDE.md`'s validation list, still pass.

## Not changed

- No skill or command file changed: the wrappers point at them.
- No `.gemini-plugin/` manifest or Gemini CLI extension. Antigravity also
  reads `.gemini-plugin/plugin.json`; this release targets Antigravity only.
- `agy` as a delegation target (footers, composer keys, fallbacks) is an
  existing, separate topic.
- Nothing was submitted to the Antigravity Marketplace, which is curated and
  expects a logo and suggested prompts.
