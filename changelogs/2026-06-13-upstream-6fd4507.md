## Reconciliation decisions

- **GitHub templates adopted.** This fork did not previously ship `.github/` templates, so the updated issue and PR templates were added and adapted to `superpowers-extended` terminology.
- **`CLAUDE.md` not overwritten.** Upstream uses `CLAUDE.md` as contributor guidance. This fork uses `CLAUDE.md` as the Claude Code entrypoint, so replacing it would break local agent bootstrapping. The relevant contributor policy was translated into `.github/` templates and README documentation instead.
- **Branch target translated.** Upstream requires PRs target `dev`; this fork's origin currently advertises only `main`. The PR template tells contributors to target the active development branch and notes that `dev` should be used if maintainers introduce it.
- **No funding/contact links adopted.** Upstream `.github/FUNDING.yml` and issue-template contact links were unchanged by this upstream commit and are not part of this fork's update. A minimal `blank_issues_enabled: false` config was added so reports go through the disclosure templates.
