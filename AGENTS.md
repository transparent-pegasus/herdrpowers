# Agents Guide

This repository IS the herdrpowers plugin. The payload lives at the repo root: `skills/` (16 skills), `commands/` (7 workflows), `docs/` (framework docs). Plugin manifests: `.claude-plugin/`, `.codex-plugin/`, `.cursor-plugin/`, `.agents/plugins/marketplace.json`, and for OpenCode 1/2 `package.json` with its entry point `.opencode-plugin/index.mjs`.

When editing pack behavior, edit the payload directories directly; this is the upstream plugin, not a consumer to initialize. Read `CLAUDE.md` for MIT/`NOTICE` duties, changelogs, and validation, and `skills/orchestration/references/profiles.md` for routing. Separate delegated targets use reset-backed Herdr panes. With a selected profile, self-target `delegate` requires fresh in-process subagents for work and reviews; other owner-session modes permit reported self-review and optional subagents at the active owner's judgment. Preserve no-profile independence, disabled gates, test ownership, and the five-round cap. Workers never re-delegate; explicit owner handoff is distinct. Lifecycle is a separate strict boolean, false by default. These rules apply to every agent working on this repo.
