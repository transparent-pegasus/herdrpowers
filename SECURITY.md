# Security policy

## Supported versions

Security fixes target the latest released version. Update older installations
before reporting a problem.

## Reporting a vulnerability

Open an [issue](https://github.com/transparent-pegasus/herdrpowers/issues/new)
requesting a private reporting channel. Include only the affected version and
a general description; do not post exploit details, credentials, or private
repository content. A maintainer will arrange a private follow-up for the
reproduction steps, impact, and proposed fix.

Herdrpowers instructs coding agents and invokes local tools with the agent's
existing permissions. Review installed skills, repository configuration, and
delegated commands before granting access to sensitive workspaces.
